# Exercise 04: Refactoring

**Goal**  
Improve readability without changing behavior.

**Scenario**  
The cart or promotion code is getting a little repetitive.

**Steps**

1. Pick one small method
2. Ask Copilot for a readability refactor
3. Review the suggestion carefully
4. Re-run tests

**Suggested Copilot prompt**  
Refactor this code for readability without changing behavior. Keep it understandable for early-career engineers.

**Acceptance criteria**

- Behavior unchanged
- Code is easier to read
- Tests still pass
