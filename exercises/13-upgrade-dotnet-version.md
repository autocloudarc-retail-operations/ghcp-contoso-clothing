# Exercise 13: Upgrade the .NET Version

## Goal

Practice a framework upgrade from .NET 8 to .NET 10 with Copilot-assisted modernization.

## Scenario

The team wants to learn how an app modernization workflow can help plan and perform a runtime upgrade.

## Steps

1. Review the current .NET version used by the solution
2. Use the GitHub Copilot app modernization extension feature to assess the upgrade
3. Update the target framework and related configuration as appropriate
4. Resolve build or test issues with Copilot assistance
5. Record any upgrade notes in the documentation

## Suggested Copilot Prompt

Help me upgrade this learning repo from .NET 8 to .NET 10 using the app modernization workflow. Keep changes minimal and explain any compatibility issues.

## Acceptance Criteria

* The target framework upgrade is planned or implemented
* Build and tests are run after the change
* Any required code or package updates are documented
* The upgrade notes are understandable for early-career engineers
