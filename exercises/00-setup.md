# Exercise 00: Setup

**Goal**  
Build and run the workshop repo locally.

**Scenario**  
You just cloned `ghcp-contoso-clothing` and need to confirm everything works.

**Steps**

1. Run `dotnet restore`
2. Run `dotnet build`
3. Run `dotnet test`
4. Run `dotnet run --project src/ContosoClothing.Api`
5. Open Swagger

**Suggested Copilot prompt**  
Explain the purpose of this repository and the quickest way to verify it works locally.

**Acceptance criteria**

- Solution restores
- Build passes
- Tests pass
- Swagger opens successfully
