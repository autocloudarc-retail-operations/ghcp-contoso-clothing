# Exercise 01: GitHub Flow

**Goal**  
Practice a complete small GitHub flow change.

**Scenario**  
Improve one short README section through a normal issue and pull request flow.

**Steps**

1. Create an issue for a small README improvement
2. Create a branch
3. Make the change
4. Build or test if needed
5. Open a PR

**Suggested Copilot prompt**  
Suggest a small README improvement for this learning repo and keep it beginner-friendly.

**Acceptance criteria**

- Issue created
- Branch created
- Small change committed
- Pull request opened with a concise summary
