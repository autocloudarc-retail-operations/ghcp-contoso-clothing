# Exercise 17: Review and Refresh the README

## Goal

Update the README so it reflects the current state of the repo.

## Scenario

Several exercises may have changed setup, data sources, runtime version, or migration notes. The README should stay useful for new learners.

## Steps

1. Review the README against the current repo behavior
2. Identify outdated, missing, or confusing sections
3. Make a concise update that helps a new participant get started
4. Ask Copilot to review the README for clarity
5. Verify links, commands, and section names still make sense

## Suggested Copilot Prompt

Review this README against the current repository and suggest concise updates for accuracy, setup clarity, and beginner-friendliness.

## Acceptance Criteria

* README reflects the current app and setup path
* Commands and links are accurate
* The tone remains beginner-friendly
* The update avoids unnecessary detail
