# Exercise 15: Plan Azure Migration in Plan Mode

## Goal

Turn the migration discussion into an implementation plan.

## Scenario

After exploring Azure options, the team wants a scoped plan that can be reviewed before any migration work begins.

## Steps

1. Switch from Ask mode to Plan mode or use the app modernization extension planning feature
2. Use the notes from the previous exercise as input
3. Break the migration into small reviewable steps
4. Include validation and rollback considerations
5. Keep the plan appropriate for a learning repository

## Suggested Copilot Prompt

Create a small implementation plan for migrating this .NET learning API to Azure. Use the previous migration notes and keep the plan reviewable.

## Acceptance Criteria

* A migration plan exists before implementation starts
* The plan includes validation steps
* The scope is small enough for a workshop extension
* Risks and assumptions are visible
