# Exercise 06: Documentation and PR Summary

**Goal**  
Practice documentation updates and PR communication.

**Scenario**  
You made a small change and need to document it well.

**Steps**

1. Update README or a docs file
2. Ask Copilot for a concise PR summary
3. Review and edit the summary

**Suggested Copilot prompt**  
Write a concise PR summary for this change, including what changed, how it was tested, and any review notes.

**Acceptance criteria**

- Documentation updated
- PR summary is concise and accurate
- Test evidence is included
