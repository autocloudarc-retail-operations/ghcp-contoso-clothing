# Exercise 16: Implement an Azure Migration Increment

## Goal

Implement one small part of the Azure migration plan.

## Scenario

The plan is ready, and the team wants to make a narrow, reviewable migration change rather than a large deployment rewrite.

## Steps

1. Pick one implementation step from the migration plan
2. Make the smallest useful change
3. Add documentation or configuration notes as needed
4. Validate the app still builds and tests locally
5. Prepare a PR summary that explains the migration increment

## Suggested Copilot Prompt

Implement one small step from this Azure migration plan. Keep the change reviewable, document assumptions, and preserve local development behavior.

## Acceptance Criteria

* One migration increment is implemented or clearly staged
* Local build and test expectations are still clear
* Documentation explains the new migration-related change
* The PR summary describes what changed and what remains
