# Exercise 03: Debugging

**Goal**  
Diagnose an API behavior problem.

**Scenario**  
A cart quantity or promo validation path is not behaving the way a teammate expects.

**Steps**

1. Reproduce the behavior with a test or Swagger
2. Ask Copilot to explain the likely cause
3. Make the smallest safe fix
4. Re-run tests

**Suggested Copilot prompt**  
Explain why this cart quantity or promo validation behavior fails and suggest the smallest safe fix.

**Acceptance criteria**

- Root cause explained clearly
- Small fix applied
- Tests pass
