# Exercise 14: Explore Azure Migration in Ask Mode

## Goal

Use Ask mode to reason about a possible Azure migration before changing files.

## Scenario

The team wants to understand hosting options for the API, but they are not ready to implement infrastructure yet.

## Steps

1. Ask Copilot to review the app shape and suggest Azure hosting options
2. Compare a small number of realistic paths
3. Identify assumptions, risks, and open questions
4. Capture the recommendation in a short note or planning section
5. Avoid making implementation changes in this exercise

## Suggested Copilot Prompt

In Ask mode, review this .NET learning API and suggest a simple Azure migration approach. Compare options, assumptions, and risks without editing files.

## Acceptance Criteria

* A migration direction is discussed and captured
* Tradeoffs are written in beginner-friendly language
* No infrastructure or deployment changes are made yet
* Open questions are clear enough for the next exercise
