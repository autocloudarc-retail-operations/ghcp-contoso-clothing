# Exercise 18: Review Workshop Documentation

## Goal

Refresh the workshop docs and exercises after the repo has evolved.

## Scenario

The learning path now includes data refactoring, modernization, migration planning, and documentation automation. The supporting docs should still feel coherent.

## Steps

1. Review the docs and exercise list as a learner
2. Look for missing context or outdated references
3. Update one or two docs where the learning flow needs help
4. Keep the docs concise and practical
5. Ask Copilot to check for confusing instructions

## Suggested Copilot Prompt

Review these workshop docs and exercises for flow, clarity, and outdated information. Suggest small improvements without rewriting everything.

## Acceptance Criteria

* At least one documentation improvement is made or proposed
* The exercise sequence remains easy to follow
* Newer modernization topics fit naturally into the workshop story
* The docs stay concise
