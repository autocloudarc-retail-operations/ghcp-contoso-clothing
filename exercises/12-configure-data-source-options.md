# Exercise 12: Configure Data Source Options

## Goal

Make the app's data source choices easier to understand, switch, and document.

## Scenario

The repo now has more than one possible data source. Learners need a clear way to know which mode they are using and how to change it.

## Steps

1. Review the available data source paths
2. Choose a simple configuration pattern for local development
3. Add a small guardrail or startup message if it helps learners
4. Update README or docs with the available options
5. Re-run the relevant verification steps

## Suggested Copilot Prompt

Help me make the data source configuration clearer for this learning repo. Prefer simple settings, clear names, and documentation over complex abstractions.

## Acceptance Criteria

* Data source options are easy to identify
* Local setup documentation reflects the available choices
* The default path remains beginner-friendly
* Tests or manual verification confirm the app still runs
