# GitHub Flow Guide

## 1. Create issue

Write a small issue such as a README fix, test improvement, or API enhancement.

## 2. Create branch

Create a short-lived branch from `main` for that one change.

## 3. Make small change

Keep the scope focused so the PR is easy to review.

## 4. Commit

Use a clear commit message and include test evidence in your notes.

## 5. Open pull request

Summarize what changed, why it changed, and how you tested it.

## 6. Review

Ask for feedback, respond to comments, and update the branch.

## 7. Merge

Merge once the change is understood, reviewed, and validated.
