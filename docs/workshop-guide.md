# Workshop Guide

Use `ghcp-contoso-clothing` as a small, practical lab across three 2-hour sessions.

## Day 1

- Review the requirements and repo layout
- Run the API and Swagger
- Ask Copilot to explain `Program.cs`
- Practice a small feature, refactor, unit test, or debugging task

## Day 2

- Review `.github/copilot-instructions.md`
- Try the reusable prompt files in `.github/prompts`
- Compare weak prompts with better prompts using context, intent, clarity, and specificity

## Day 3

- Review secure coding notes
- Make a small, scoped improvement
- Open a PR, review it, and discuss tradeoffs
- Use extension challenges for follow-up practice

## Suggested instructor flow

1. Build confidence with setup and Swagger
2. Keep changes small and reviewable
3. Have learners explain generated code before merging it
4. Reinforce testing and secure coding checks with every change
